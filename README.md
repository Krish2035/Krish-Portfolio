## 🚀 Key Features

- **⚡ Blazing Fast Architecture:** Built with Vite and React 19 for instantaneous page loads and smooth client-side hydration.
- **🌌 Immersive 3D Graphics:** Powered by Three.js particle geometry and smooth Framer Motion animations.
- **📱 Progressive Web App (PWA):** Installable directly to mobile home screens and desktop apps with offline caching support.
- **🔍 Full SEO Optimization:** Schema.org JSON-LD structured data (`Person`, `WebSite`, `ProfilePage`), XML Sitemap, Open Graph, and Twitter metadata to achieve #1 ranking on search engines for *"Krish Padshala Portfolio"*.
- **📬 Recruiter Connect:** Direct inbox forwarding via FormSubmit with optional Node/Express + MongoDB persistence.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite, Three.js, `@react-three/fiber`, Framer Motion, Lucide Icons
- **Backend:** Node.js, Express.js, RESTful APIs, JWT Authentication
- **Database:** MongoDB, Mongoose ODM, MongoDB Atlas
- **Styling:** Modern CSS3 Variables, Glassmorphism, Responsive Grid & Flexbox
- **Deployment:** Vercel (Frontend), Node/Express Server (Backend)
